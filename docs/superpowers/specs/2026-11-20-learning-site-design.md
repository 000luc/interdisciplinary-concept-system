# 跨学科概念学习站设计

## 目标

把现有 GitHub 仓库升级为一个无需安装、打开即可学习的静态网站。网站继续使用仓库中的 600 个概念、24 周计划和练习体系，同时提供搜索、筛选、每日任务、复习队列和浏览器本地进度记录。

成功标准：

- GitHub Pages 可直接访问，桌面和手机均可使用。
- 600 个概念可搜索、按领域、主题、优先级和掌握状态筛选。
- 学习者可以完成每日任务、更新概念状态、查看到期复习并导出自己的进度。
- 学习进度默认只保存在当前浏览器，不上传服务器，也不写入公开仓库。
- 原有 Markdown、Excel 和生成脚本保持可用。

## 范围

包含：

- 总览页、今日学习、24 周计划、概念库、复习队列、学习记录。
- 浏览器 `localStorage` 进度、JSON 导入导出、开始日期调整。
- GitHub Pages 静态部署。
- 响应式布局、键盘操作、减少动画偏好和基础无障碍支持。

不包含：

- 账号登录、跨设备云同步、多人协作和后台服务。
- 在网站内修改 Markdown 或 Excel 源文件。
- 自动生成新的概念内容或调用 AI。

## 技术架构

- 使用无构建依赖的静态 HTML、CSS 和 JavaScript，放在 `docs/`。
- `scripts/build_site_data.py` 从 `scripts/build/content.json` 生成 `docs/data.js`，避免站点运行时解析本地 JSON。
- `docs/index.html` 提供应用骨架，`docs/app.js` 负责状态、筛选、复习和渲染，`docs/styles.css` 负责响应式界面。
- GitHub Pages 从 `main` 分支的 `/docs` 发布。
- 不依赖后端或第三方数据服务；图标脚本若加载失败，不阻断文字功能和核心操作。

## 页面结构

桌面端使用固定侧栏和主内容区；手机端改为顶部品牌栏和横向导航。页面切换通过 URL hash 保留，例如 `#library`、`#plan`。

### 总览

- 总进度、已完成学习日、累计分钟、已接触概念、A 级掌握数和到期复习数。
- 当前周及最近 5 个每日任务。
- 六个领域的进度分布。
- 六个领域节点组成的知识网络画布，节点大小和亮度反映进度；不是装饰图。
- 继续今日学习和进入概念库的主要入口。

### 今日学习

- 根据用户设置的计划开始日期确定当前学习日；日期早于计划开始日时显示第 1 天预览。
- 展示当日 60 分钟任务顺序、现实案例练习和输出要求。
- 自动推荐当日相关概念：扫描日按主题提取 20 个概念，重点概念日按任务中的概念名提取。
- 支持完成当天任务、记录实际分钟、填写当日笔记。

### 24 周计划

- 24 周按阶段分组，每周展开后显示 5 个每日任务、当日产出和本周输出。
- 每项任务可标记完成，周进度实时更新。
- 阶段标签区分六个领域、跨领域整合和综合项目。

### 概念库

- 搜索范围包含概念名、解释、案例、易混点和关联概念。
- 筛选条件包括领域、主题、优先级、掌握状态。
- 每页显示 30 个结果，支持上一页和下一页。
- 概念详情使用对话框展示定义、案例、易混点、关联概念、深度机制、边界、反例和来源。
- 可更新掌握状态、信心评分、最近复习日期和个人备注。
- 掌握状态为“未接触、认识、理解、应用、能迁移”。

### 复习队列

- 无复习日期的已学习概念显示为“待安排”。
- 下次复习日期早于或等于今天的概念进入“今日到期”。
- 严重逾期超过 7 天的概念单独标记。
- 复习操作提供“忘记、模糊、记住”三个结果，分别设置下次复习间隔为 1 天、3 天和当前状态对应的 7 至 90 天。
- 可按领域和优先级筛选。

### 学习记录

- 显示学习日完成数、累计分钟、概念状态分布和输出完成情况。
- 每周可选择周次，填写最大收获、最大困惑、跨领域连接、自评分和下周动作。
- 支持调整计划开始日期、导出 JSON、导入 JSON 和清空本地进度。
- 清空操作必须二次确认。

## 本地数据模型

浏览器键名为 `interdisciplinary-learning-v1`，数据格式固定为：

```json
{
  "version": 1,
  "settings": {
    "startDate": "2026-11-23"
  },
  "days": {
    "1": {
      "completed": false,
      "minutes": 0,
      "note": ""
    }
  },
  "concepts": {
    "SOC-001": {
      "status": 0,
      "confidence": 0,
      "lastReviewed": "",
      "nextReview": "",
      "note": ""
    }
  },
  "weeks": {
    "1": {
      "gain": "",
      "confusion": "",
      "connection": "",
      "score": 0,
      "nextAction": ""
    }
  }
}
```

- 状态索引映射为 `0=未接触`、`1=认识`、`2=理解`、`3=应用`、`4=能迁移`。
- 导入时校验版本、对象结构、日期格式、状态范围和概念 ID；不安全或未知 ID 被忽略，其他有效记录保留。
- `localStorage` 写入失败时显示明确提示，页面仍可浏览但不承诺保存。
- 导出文件名使用 `learning-progress-YYYY-MM-DD.json`。

## 交互与视觉

- 主体使用深墨色文字、暖白背景、深青色主操作和琥珀色提醒，避免单一色系。
- 标题使用紧凑工具型排版，正文不小于 16px，辅助标签不小于 14px。
- 卡片圆角不超过 8px；嵌套区域使用分隔线和背景差异，不堆叠卡片。
- 主按钮使用清晰文字和 Lucide 图标；图标必须有可见文字或 `aria-label`。
- 所有筛选器、对话框、分页和任务按钮均可用键盘操作。
- 手机端不出现横向溢出，长概念名和中文段落可换行，按钮高度不小于 44px。
- 支持 `prefers-reduced-motion`；知识网络画布在高分屏使用设备像素比缩放。

## 错误与边界

- 浏览器不支持 `localStorage`：显示只读模式提示。
- 导入无效 JSON：不覆盖当前数据，并显示具体失败原因。
- 日期晚于计划结束：总览显示最终复习状态，今日学习定位到第 24 周。
- 日期早于计划开始：显示距离开启天数，并提供第 1 天预览。
- 概念筛选无结果：显示空结果和清除筛选按钮。
- 外部图标脚本失败：隐藏占位图标，文字标签和交互保持可用。

## 部署

- 网站文件提交到 `docs/`。
- GitHub Pages 使用 `main` 分支和 `/docs` 目录发布。
- 地址固定为 `https://000luc.github.io/interdisciplinary-concept-system/`。
- README 首屏增加在线学习入口，同时保留 Markdown、Excel 和重新生成说明。

## 验收

- `data.js` 包含 600 个概念、120 个学习日、24 周和 24 个输出。
- 概念搜索、四个筛选器、分页和详情对话框可用。
- 更新概念状态后，总览、概念统计和复习队列同步变化。
- 刷新页面后本地进度仍存在；导出后可重新导入并恢复。
- 桌面 1440px、平板 820px、手机 390px 截图无遮挡、无横向溢出、文字不截断。
- 今日任务、计划任务、概念详情、复习按钮和记录表单通过真实浏览器操作测试。
- GitHub Pages 返回成功状态，线上首页可以加载数据并完成一次状态更新。
